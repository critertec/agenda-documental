# Agenda · Documental de cierre Soy Digital 2026

- `index.html` — vista pública (23–27 nov, lunes a viernes). Muestra libre/ocupado y la entidad; permite agendar.
- `equipo.html` — vista interna (16–28 nov, lunes a sábado). Muestra todo el detalle; permite crear, editar y eliminar. Se abre con `equipo.html#k=CLAVE`.
- `config.js` — aquí va la URL de la aplicación web de Google Apps Script.
- `apps-script/Code.gs` — backend. **No** hace falta subirlo a GitHub; se pega en Google Apps Script.

Sin `API_URL` en `config.js`, ambas páginas funcionan en modo demostración (clave interna: `demo`).

La guía completa de publicación está en el documento "Guía de publicación · Agenda del documental".
